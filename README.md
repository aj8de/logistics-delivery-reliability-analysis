Logistics Delivery Reliability Analysis
Project Overview
This project examines delivery appointment performance across customers and freight routes using logistics shipment data.
The analysis focuses on delivery reliability, out-of-window deliveries, pickup performance, and data-quality limitations to help decision-makers better understand operational service performance.
Business Questions
How does delivery appointment adherence vary over time?
Which customers experience the highest number of out-of-window deliveries?
How does pickup performance compare with delivery performance?
How does the definition of on-time delivery affect reported performance?
What data-quality limitations should decision-makers consider?

Key Findings
The supplied on-time delivery flag indicates that 44.61% of deliveries were within the defined appointment window of ±120 minutes.
Using a stricter definition of delivery on time—arrival at or before the scheduled time—the rate was 33.28%.
The difference between these measures highlights how KPI definitions can affect reported operational performance.
Data-quality issues were identified that require consideration when interpreting the results.
Data Quality and Limitations
The analysis identified several limitations:
Inconsistent city and state information for some facilities.
486 trips with delivery timestamps earlier than pickup timestamps.
7,450 trips with idle hours exceeding trip duration.
8,471 trips without matching fuel purchases.
These limitations affect how some operational measures should be interpreted. The project is descriptive and does not establish causal relationships.
